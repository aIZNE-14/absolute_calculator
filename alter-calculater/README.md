# UMBAC

Universal Multi-Base Advanced Calculator: локальное Python-приложение с веб-интерфейсом и CLI для перевода оснований, символьного матанализа, ограниченного набора задач квантовой механики и астрофизических моделей.

## Установка и запуск

Требуется Python 3.11+.

```powershell
python -m pip install -r requirements.txt
python app.py
```

Откройте `http://127.0.0.1:8000`. Веб-сервер привязан к loopback-интерфейсу. CLI:

```powershell
python -m umbac.cli --list-ops
python -m umbac.cli --op base --expr 255 --base-in 10 --base-out 16
python -m umbac.cli --op analysis.derive --expr "x*sin(x)" --params '{"var":"x"}'
python -m umbac.cli --op astro.friedmann --params '{"H0":70,"Om":0.3,"OL":0.7,"z":1}'
python -m umbac.cli --op quantum.schrodinger --expr harmonic:1 --params '{"x_min":-8,"x_max":8,"n_points":1000,"n_states":5}'
python -m umbac.cli --repl
```

Точность и соглашения можно менять флагами `--dps`, `--frac-digits`, `--angle-unit rad|deg` и `--units atomic|SI`. Программный интерфейс: `from umbac import CalcConfig, UniversalAdvancedCalculator`.

Проверки: `python -m pytest -q`.

## Структура

`umbac/config.py` содержит `CalcConfig`; `errors.py` — иерархию диагностических ошибок; `base_converter.py` — позиционные системы; `expr_parser.py` — безопасный разбор; `analysis.py`, `quantum.py`, `astro.py` — численные движки; `constants.py` — константы и минимальные SI-конверсии; `facade.py` — `UniversalAdvancedCalculator` и сериализуемый `CalcResult`; `cli.py` — командный интерфейс.

## Основания

Поддерживаются все целые основания от 2 до 64. Алфавит: `0-9` = 0–9, `A-Z` = 10–35, `a-z` = 36–61, `+` = 62, `/` = 63. До основания 36 ввод букв нечувствителен к регистру; начиная с 37 регистр значим. Для base 63 и 64 ведущий `+` трактуется как цифра; для меньших оснований он может обозначать знак. Конечные входные дроби хранятся как точные рациональные числа; `from_decimal` округляет round-half-up, а `from_decimal_periodic` показывает повторяющийся период в скобках.

В выражениях позиционные числовые литералы читаются в `base_in`; в основаниях до 36 последовательности допустимых цифр также читаются как число. Для неоднозначных или оснований выше 36 используйте `base(64, 'Z+')` либо `[Z+]_64`. Например, `[1F.8]_16` равно `63/2`.

## Научные модули

Матанкализ включает производные, неопределённые и определённые интегралы, пределы с отдельным анализом сторон, ряды Тейлора/Фурье, проверку тождеств и ограниченный ODE/PDE-интерфейс SymPy. Несобственные интегралы используют символический ответ, а при необходимости — численное интегрирование. Различающиеся односторонние пределы возвращаются отдельно с предупреждением.

`QuantumEngine` поддерживает собственные состояния матриц, одномерное стационарное уравнение Шрёдингера для заданных потенциалов, наблюдаемые, чистые состояния и матрицы плотности, энтропию фон Неймана, частичный след, negativity и concurrence. PPT явно отмечается как необходимый, но недостаточный критерий вне 2×2 и 2×3.

`AstrophysicsEngine` включает метрики Шварцшильда вне горизонта, модель Фридмана, предел Чандрасекара, уравнение Лейна—Эмдена и проверку гидростатического профиля. Константы сопровождаются единицами, источником и доступной неопределённостью. `Quantity.to_si()` поддерживает ограниченный список единиц.

В `cpp/base_converter.cpp` и `fortran/base_converter.f90` находятся самостоятельные целочисленные конвертеры 2–64 с алфавитом UMBAC. Они не подключены к Python-веб-серверу и не реализуют символьные или физические операции; для компиляции нужны C++17 и Fortran 2008.

## Ограничения

Это набор проверяемых вычислительных моделей, не система доказательства всех теорем и не универсальный решатель физических задач. Общие PDE, произвольные многочастичные модели, численно неустойчивые интегралы и размерностный вывод для произвольных составных единиц не решаются автоматически. `CalcConfig.timeout_s` сохраняется для API-совместимости, но жёсткое прерывание долгих символических вычислений в текущей Windows-версии не реализовано. Пользовательские Python-вызовы, импорты и доступ к атрибутам объектов в выражениях запрещены. Перед интерпретацией результата физической модели необходимо проверить принятые единицы, приближения, граничные условия и диапазон применимости.
